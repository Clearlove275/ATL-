# 率土同盟数据库 · 微信小程序

复用网页版后端（Supabase 数据库 / 登录认证 / 视觉识别 Edge Function），前端用微信小程序原生框架重写。

## 已实现（MVP）
- 邮箱注册 / 登录（一个邮箱只能注册一次；重复注册会提示并自动切到登录）
- 我的同盟列表、创建同盟、邀请码加入
- 同盟数据概览（成员数 / 记录数 / 最高武勋 / 最高势力）
- 成员列表与最新值（武勋、势力、贡献总量/周量）
- 手动录入一条记录、添加玩家
- 截图识别（调用视觉识别后端）

## 尚未实现
成员列表批量识别、视频识别、Excel/CSV、变化值对比、图表、反馈区、实时刷新。

## 打开方式
1. 微信开发者工具 → 导入项目 → 选择 miniprogram 目录。
2. AppID 可先用「测试号」（project.config.json 的 appid 字段可改）。
3. 开发阶段勾选「不校验合法域名」。
