# 率土同盟数据库

面向《率土之滨》同盟的数据统计网站：**截图 / 视频 / Excel 自动录入「武勋 / 势力值 / 贡献」**，支持**多用户同盟数据库**、**实时更新**、**任意两次时间的变化值对比**与**交互式排序**。

> 目标不是“谁氪得多、势力高谁优秀”，而是判断：谁稳定在线、谁能打、谁在关键任务中真正帮盟里推进。

## 功能特性

- 📷 **截图识别**：上传截图自动提取「武勋（功勋）」「势力值」「贡献总量」「贡献周量」；支持同盟成员列表批量识别，逐行核对。
- 🎬 **视频识别**：上传录屏自动抽帧识别并合并成成员列表。
- 📊 **Excel / CSV 导入**：上传表格自动识别表头并批量导入（仅盟主/管理员可用）。
- 🕐 **时间记录**：每次导入自动记录时间，用于变化值计算。
- 📈 **变化值对比**：任意两次时间的 Δ武勋 / Δ势力值 / Δ贡献。
- 🔀 **排序与筛选**：点击表头排序、昵称/团组搜索、图表、CSV 导出。
- 👥 **多用户同盟数据库**：每个盟一个数据库，盟友用邀请码加入并上传数据。
- ⚡ **实时更新**：Supabase Realtime 实时刷新榜单与表格。
- 🔐 **权限控制**：仅盟主/管理员可录入他人数据，成员只能录自己；支持同名认领与改名合并继承。

## 技术架构

- **前端**：原生 HTML + CSS + JavaScript（无构建步骤），纯静态单页应用。
- **数据**：Supabase（PostgreSQL + Row Level Security + Realtime）。
- **视觉识别**：Supabase Edge Function（qwen 优先、GLM 兜底），失败自动回退浏览器本地 Tesseract。

## 数据库与后端（已配置）

本站的 `config.js` **已经填好** Supabase 项目地址与公钥，数据库结构由 `supabase/schema.sql` 定义（已部署）。**普通用户无需任何配置**，打开网站注册登录即可使用。

若你需要换成自己的 Supabase 项目：按 `supabase/schema.sql` 建表，再修改 `config.js` 中的 `supabaseUrl` 与 `supabaseAnonKey`。

## 部署到任意静态托管（GitHub Pages / EdgeOne Makers / 自定义域名）

前端是纯静态文件，可部署到任意静态托管平台：

1. 托管根目录这些文件：`index.html`、`styles.css`、`app.js`、`config.js`、`ocr.js`、`store.js`。
2. 绑定你的域名（中国大陆域名需完成 ICP 备案）。
3. 把域名填入 Supabase 认证的 **Site URL**（Authentication → URL Configuration，或让我代改）。

部署后，用户直接打开域名、注册登录，即可使用真实的多用户数据库，**无需任何本地配置**。

## 使用说明

### 盟主 / 管理员

1. 注册登录 → 创建同盟 → 填写同盟名、赛季名、你的游戏昵称。
2. 把**邀请码**发给盟友；盟友注册登录后凭邀请码加入。
3. 在「导入数据」用截图 / 视频 / Excel 批量录入，或手动录入。
4. 「成员数据」排序与变化值区间、「数据图表」看排行趋势、「同盟设置」管理成员权限。

### 盟友 / 玩家

1. 注册登录 → 「我的同盟」输入邀请码加入。
2. 「导入数据」上传自己的截图 → 识别 → 核对 → 保存。
3. 只能录入自己的数据；游戏内改名后可申请继承旧名字数据。

## 数据模型

| 表 | 说明 |
| --- | --- |
| `alliances` | 同盟（名称、赛季、邀请码） |
| `alliance_members` | 用户与同盟关系及权限（owner / admin / member） |
| `players` | 盟员名单（游戏昵称、团组、职责） |
| `records` | 每次导入的快照（武勋 / 势力值 / 贡献总量 / 贡献周量 + 时间戳） |

武勋/势力值的变化值 = 「结束时间点之前最近一次快照」−「起始时间点之前最近一次快照」。
